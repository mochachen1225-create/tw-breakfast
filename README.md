# 帥哥美女早餐店

手機瀏覽器就能玩的台灣早餐店出餐遊戲。打開 `index.html` 就可以玩。

- 開店前先取店名：自己輸入、從台式諧音梗店名挑（堡你滿意、鮪你而生、肉鬆一下…），或按骰子隨機抽
- 訂單分內用、外帶、Uber 取餐（一次 5～7 樣，小費比較多）
- 出錯和結算畫面有可愛的小角色（委屈的荷包蛋、冒煙的焦吐司、嚇到的奶茶杯…）
- 五分鐘內出完 20 張單就過關，會拿到一個封號；送錯、燒焦、溢出、超時 3 次就倒店
- 一次一張訂單，做完才出下一張；畫面上方記帳：收入、賠掉、淨賺
- 主食都要搭配食材：蛋餅在煎台做，三明治／漢堡／飯糰在工作台組
- 有 🔥 的食材（荷包蛋、培根、豬排、卡拉雞）要先煎，同一種一鍋最多 3 份；熟了點一下夾去配，沒地方配就先收進保溫台，之後再點保溫台加到堡裡
- 給多了（中杯做成大杯、多加料）只收原本的錢，差額算賠；給少了那單變免費
- 飲料：按住杯子倒，停在中杯或大杯的線之間，切換無糖／半糖／全糖，再按「送」；甜度不對就變免費
- 特殊訂單：常客阿伯（第二次只寫「老樣子」）、外送單（一次 4 樣）、臨時改單
